# ☕ Buy Me A Coffee (Vyper)

My first Vyper smart contract — a simple and minimal donation system.

Users can donate at least **$5 in ETH** to the contract creator.  
The contract uses **Chainlink price feeds** to convert ETH to USD in real time.

## Features
- Minimal, gas-efficient Vyper code
- Chainlink oracle integration
- $5 minimum enforced per donation
- Only the creator can withdraw the funds

## Tech Stack
- Vyper 0.4.1
- Chainlink AggregatorV3Interface
